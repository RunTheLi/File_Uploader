3.3 Prisma Schema
เราออกแบบ Database ด้วย Prisma Schema ซึ่งมี 3 Models

User

เก็บข้อมูลผู้ใช้:
model User {
  id        Int      @id @default(autoincrement())
  username  String   @unique
  password  String
  createdAt DateTime @default(now())

  folders Folder[]
  files   File[]
}


Folder

เก็บข้อมูล Folder และความสัมพันธ์กับ User:
model Folder {
  id        Int      @id @default(autoincrement())
  name      String
  createdAt DateTime @default(now())

  userId Int
  user   User @relation(fields: [userId], references: [id], onDelete: Cascade)
  files  File[]
}


File

เก็บข้อมูลไฟล์และความสัมพันธ์กับ User และ Folder:
model File {
  id           Int      @id @default(autoincrement())
  filename     String
  originalName String
  mimeType     String
  size         Int
  url          String
  createdAt    DateTime @default(now())

  userId   Int
  user     User   @relation(fields: [userId], references: [id], onDelete: Cascade)

  folderId Int?
  folder   Folder? @relation(fields: [folderId], references: [id], onDelete: SetNull)
}


ความสัมพันธ์ของ Database
User

หนึ่ง User มีหลาย Folders และ Files

1 : Many

Folder

หนึ่ง Folder มีหลาย Files


File

File เป็นของ User หนึ่งคน



File สามารถอยู่ใน Folder หรือไม่อยู่ใน Folder ก็ได้

เรายังได้กำหนด Referential Actions:
- onDelete: Cascade — เมื่อลบ User จะลบ Folder และ File ของ User คนนั้นด้วย
- onDelete: SetNull — เมื่อลบ Folder ไฟล์ที่อยู่ใน Folder จะไม่ถูกลบ แต่จะกลายเป็นไฟล์ที่ไม่มี Folder
